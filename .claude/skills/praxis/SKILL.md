name: praxis
description: Entry point — start or resume a Praxis Course. Reads AGENTS.md + the three progress files + CURRICULUM.md and drives the current Module's Tutor loop.
---
Read `AGENTS.md` in full and follow it exactly. Then read `progress/PROGRESS.local.md`,
`progress/NOTES.local.md`, `progress/STRATEGY.local.md`, and `CURRICULUM.md`. Tell the learner "you are
here" in one line, then run the Tutor-mode loop for the current Module. Default intent: continue.
