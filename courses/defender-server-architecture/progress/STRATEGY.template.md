# Teaching strategy

How to teach *you* — pace, hint aggressiveness, recall lead, modality. The Conductor (the `coach`
skill) rebuilds this after each Module. Tunes delivery only — never the graduation bar.

- **Pace:** 1–2 Modules per sitting; stop on a clean win.
- **Hints:** graduated — nudge → name the concept → partial → full solution only if explicitly asked.
- **Recall lead:** open each new sitting with one cold Recall of an earlier Module.
